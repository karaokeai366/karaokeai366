# UX Principles

## Participant mobile UI

The participant should be able to:
- join by QR code;
- choose a display name;
- search for songs;
- see queue position;
- see ownership of each queue entry;
- select key;
- test microphone;
- start/stop microphone;
- restart a song when allowed;
- see remaining restart credits;
- see final score after each completed song.

## Host UI

The host should be able to:
- create/end session;
- start a round;
- choose number of songs contributing to final score;
- see connected devices and their health;
- receive host transfer recommendations;
- approve or decline transfer;
- choose any participant as transfer target;
- moderate queue;
- control playback;
- show/hide results;
- end a round.

## TV UI

The TV should emphasize:
- singer name;
- song title;
- lyrics;
- progress;
- stage state;
- result reveal;
- round summary;
- QR code when inviting participants.

## Friendly interaction

The UI should be touch-first, large enough for party use, responsive on phones, and readable from a TV at distance.

Avoid exposing technical terms such as CPU score or WebRTC status to ordinary participants. Those belong in diagnostics/admin views.
